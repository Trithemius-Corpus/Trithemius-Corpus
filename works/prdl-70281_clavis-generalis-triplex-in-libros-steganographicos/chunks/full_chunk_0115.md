*Mode XXVIII. Like the preceding one, it uses alternate words, and transfers the signifying letter to the ninth.*

Mode 28, like the preceding one, uses alternate words, of which the first is empty, the second signifying, the third again empty, the fourth signifying, and so on in succession. It transfers each letter to the ninth following, so that for A, k is taken; for b, l; for c, m; and so on, as will appear in the secret alphabet. *Mode XXIX. It uses alternate words, and the first letter of each signifying word is transferred to the tenth.*

Mode 29 likewise uses alternate words, as the preceding ones do, beginning with one empty word, to which another signifying word is immediately joined; again one empty word, and again one signifying word, and so on in succession to the end of the proposed narrative. But the first letter of each signifying word is transferred to the eleventh following, so that for A, l is taken; for b, m; for c, n; and so on, as appears in the alphabet itself.
